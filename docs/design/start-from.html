Usability pass · #358 · for the owner's pick

Starting a new project

The "Start from" step above a new project's form is a list of underlined links with the same weight: an empty form, each worked example, "Answer a few questions", and "A copy of …" for every earlier project of that template, all above the form. Two directions make the four kinds of start clear. Each still opens a filled form with a preview (M8).

What to decide

  1. Which direction: P1 (suggested) a step before the form, or P2 starts inside the template picker (#357).
  2. Whether "Answer a few questions" is the default first choice for a template that has questions.

P1 · A short step before the form

Suggested
  • After picking a template, one screen asks "How do you want to start?" with four choices as large options, each with a line saying what it does: Answer a few questions (first, when the template has them), Start from an example (opens a short list of the worked examples), Copy an earlier project (the three most recent, then a search), Empty form.
  • The form opens filled, with "Change how you started" at its top.
