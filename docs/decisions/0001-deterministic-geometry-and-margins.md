# 0001: Deterministic geometry, and margins instead of verdicts

Status: Accepted (October 2026)

## Context
Kerf produces cut lists, angles, and structural sanity checks for things people hang from. A wrong number wastes wood at best. A structural result worded as "safe" claims more than a template calculation can support. See `PRODUCT.md` core principles 1 and 2.

## Decision
- Every dimension, angle, and quantity comes from template code in `packages/core`. Nothing generated by an AI model is ever used as a dimension, angle, quantity, or diagram.
- Structural checks report margins under stated assumptions ("margin 2.1x"). Code and copy never say "safe," "unsafe," "pass," or "fail."
- Structural inputs that change the answer (species and grade, rider weights, swing angle, dynamic factor, deflection limit, hardware ratings) have no hidden defaults. The user enters or confirms each one, and every result shows them.
- Amended November 2026 (#355): Kerf may suggest a structural input from a named source and edition or a stated rule of thumb. The suggestion shows its basis and stays a suggestion until the user confirms it, and a check never treats an unconfirmed suggestion as confirmed. Values only the user or the boards bought can say (rider weights, the grade stamp, a manufacturer's rating) are never suggested, and neither is a value with no published basis, such as the dynamic factor.
- Amended 2 November 2026 (#417): what confirming means. A suggestion is stored with its basis and stays unconfirmed until the user ticks it in the structural review or changes it; saving the form does not confirm it. A check that uses an unconfirmed suggestion still reports its margin, labeled as using a suggested value, with the basis, and the review lists the suggestion under To do. The server, not the client, records which values are suggestions. The second engineering review found that "until the user confirms it" had been built as "until the form is saved", with the basis lost after save and the value reported as entered.

## Consequences
- An AI explanation layer, if added later, can explain a step but can never be the source of a number.
- Results are less reassuring to read. That is intended: final structural decisions rest with the owner, experienced builders, and manufacturer specifications.
